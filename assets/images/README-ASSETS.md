# 🎨 Panduan Penempatan Karya Gambar & Ilustrasi Asli

Folder ini adalah tempat Anda meletakkan semua karya ilustrasi buatan tangan Anda sendiri. Web app sudah dirancang dengan rasio aspek standar industri buku anak dan frame estetis.

---

## 📁 Daftar File & Rekomendasi Resolusi:

### 1. Avatar / Maskot Ilustrator:
- **File saat ini:** `mascot-artist.png` *(sudah terpasang di Hero & Navbar)*
- **Rekomendasi format:** PNG transparan atau JPEG
- **Rekomendasi ukuran:** 800 x 800 px (1:1)

### 2. Karakter Buku Anak (Character Showcase):
Ganti file placeholder di `assets/images/` atau cukup sesuaikan nama file di `app.js`:
- `char-1.png` : Karakter 1 (Rekomendasi 800 x 800 px atau 600 x 600 px)
- `char-2.png` : Karakter 2 (Rekomendasi 800 x 800 px)
- `char-3.png` : Karakter 3 (Rekomendasi 800 x 800 px)
- `char-4.png` : Karakter 4 (Rekomendasi 800 x 800 px)
- `char-5.png` : Karakter 5 (Rekomendasi 800 x 800 px)
- `char-6.png` : Karakter 6 (Rekomendasi 800 x 800 px)

### 3. Storybook Double-Page Spread (Hamparan 2 Halaman Buku):
- `spread-1.jpg` : Halaman buku cerita anak 1 (Landscape, rekomendasi 1920 x 1080 px atau 2400 x 1350 px, rasio 16:9)
- `spread-2.jpg` : Halaman buku cerita anak 2 (Landscape 16:9)
- `spread-3.jpg` : Halaman buku cerita anak 3 (Landscape 16:9)

### 4. Behind The Scenes / Video Thumbnail:
- `bts-1.jpg` : Cuplikan proses menggambar / Procreate time-lapse (Rasio 9:16 untuk format Reels/TikTok/Shorts, atau 1:1)
- `bts-2.jpg` : Cuplikan rekaman Voice Acting di depan microphone
- `bts-3.jpg` : Sketchbook tour / proses sketsa konsep

---
> 💡 **Tip:** Anda juga bisa mengganti link gambar langsung di file `app.js` pada variabel data `PORTFOLIO_DATA`.
